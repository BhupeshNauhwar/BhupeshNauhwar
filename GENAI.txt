Convert the existing Spring Boot backend to .NET 8 Web API while maintaining the same functionality, API endpoints, and database schema. Ensure compatibility with the existing Angular frontend.

Set up Entity Framework Core with the existing MySQL database schema, including all models, relationships, and data annotations for the motorcycle showroom system.

Convert the entire Java Spring Boot + Angular application to Node.js + React, maintaining all functionality including authentication, product management, cart operations, and the premium UI design.

## 🚀 Getting Started

### 📋 Prerequisites

- **Node.js** (v18+)
- **Java** (17+)
- **.NET** (8.0+)
- **MySQL** (8.0+)
- **Maven** (3.6+)

### 🏃♂️ Quick Start Guide

#### Option 1: Run Individual Phases

```bash
# Phase 1: Java + Angular
cd java_angular/product && mvn spring-boot:run
cd java_angular/product-frontend && npm install && ng serve

# Phase 2: .NET + Angular  
cd donet_Angular/ProductApi && dotnet run
cd donet_Angular/product-frontend && npm install && ng serve

# Phase 3: React + Node.js
cd ReactNode/backend && npm install && npm start
cd ReactNode/frontend && npm install && npm start

# Phase 4: Polyglot Microservices
cd polyglot && ./start-all-services.bat
```
